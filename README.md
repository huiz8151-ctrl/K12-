# PhysicsLab Pro - 二力平衡交互学习系统

## 项目概述

这是一个为 12 岁学生设计的物理学习互动系统，专注于"二力平衡"（Two-Force Balance）的探究式学习。系统采用**四步学习周期**，将复杂物理概念转化为实际动手体验。

## 四步学习流程

| 步骤 | 页面 | 目的 | 学习活动 |
|-----|------|------|---------|
| 1️⃣ **提出问题** | `提出问题.html` | 建立认知冲突 | 观察生活中的平衡现象（桌上的书、悬挂的灯） |
| 2️⃣ **动手实验** | `lesson-balance.html` | 手脑并用探索 | 调整力量大小和方向，观察实时 Canvas 可视化 |
| 3️⃣ **记录归纳** | `记录归纳.html` | 数据驱动发现 | 分析实验数据，发现二力平衡的四个条件 |
| 4️⃣ **应用验证** | `应用验证.html` | 知识迁移 | 在真实场景中应用原理，澄清常见误区 |

## 核心物理知识

### 二力平衡定义
物体受到两个力的作用时保持**静止或匀速直线运动**的状态。

### 四个必要条件（四条件原理）

1. **同体** - 两个力必须作用在**同一个物体**上
2. **等大** - 两个力的大小必须**相等** (|F₁| = |F₂|)
3. **反向** - 两个力的方向必须**相反**（相差 180°）
4. **共线** - 两个力的作用线必须在**同一直线**上

### 常见误区

❌ **平衡力** vs ✅ **相互作用力**

- 书对桌面的压力 ← 作用在**两个物体** → 这是相互作用力，不是平衡力
- 重力 ← 作用在**书上** → 支持力 ← 作用在**书上** → 这才是平衡力

## 页面功能详解

### 🟦 第1步：提出问题 (`提出问题.html`)

**目标**：激发好奇心和学习动机

- 展示生活中的平衡现象（力学可视化）
- 引导学生思考："为什么这些物体能保持平衡？"
- "开始探究"按钮 → 跳转到第2步

**交互元素**：
- 场景卡片：书与灯的可视化示例
- 实验小贴士：二力平衡的基本定义

---

### 🔷 第2步：动手实验 (`lesson-balance.html`)

**目标**：通过操作和观察发现规律

**核心功能**：

1. **力量控制器**
	- 左侧力（0-12N）：滑块 + 方向选择（向左/向右）
	- 右侧力（0-12N）：滑块 + 方向选择（向左/向右）
	- 实时计算合力 (ΣF)

2. **Canvas 可视化**
	- 矩形物体（灰色）
	- 蓝色箭头（F₁）从左侧
	- 红色箭头（F₂）从右侧
	- 箭头长度 = 力的大小
	- 箭头方向 = 力的方向

3. **状态显示**
	- 平衡状态 ✓（绿色，当 |ΣF| < 0.5N）
	- 非平衡状态（红色，当 |ΣF| ≥ 0.5N）

4. **记录列表**
	- 表格显示每次实验
	- 列：序号、左力、右力、合力、状态
	- 支持多次记录（可逆序查看）

**物理计算**：
```
F₁ = 左力 × (方向系数)  // 向右=+1，向左=-1
F₂ = 右力 × (方向系数)  // 向右=+1，向左=-1
ΣF = F₁ + F₂          // 代数和
平衡条件：|ΣF| < 0.5N  // 容差值
```

---

### 🟪 第3步：记录归纳 (`记录归纳.html`)

**目标**：从数据中发现规律

**核心功能**：

1. **实验数据表**
	- 3个预设实验组合
	- 列：实验编号、左力、右力、作用线状态、物体状态
	- 状态下拉菜单：静止(平衡) / 向左加速 / 向右加速 / 转动

2. **归纳发现面板**
	- 4个条件勾选框：同体、等大、反向、共线
	- 学生通过实验数据勾选发现的条件
	- 直观呈现二力平衡的四条件原理

3. **视频回顾**
	- 动画演示实验场景
	- "从 50N 开始，调节另一侧力的变化"

---

### 🟩 第4步：应用验证 (`应用验证.html`)

**目标**：知识迁移和误区澄清

**核心功能**：

1. **三大场景卡片**
	- 场景1：桌上的书（重力 ↔ 支持力）
	- 场景2：风筝（风力、重力、线的拉力）
	- 场景3：拔河绳（左拉力 ↔ 右拉力）
	- 学生选择正确的平衡力对

2. **易错辨析**
	- 标题：平衡力 vs 相互作用力
	- 错误示例：压力和支持力（不是平衡力）
	- 正确示例：重力和支持力（真正的平衡力）
	- 向量图解展示

3. **概念澄清**
	- 直观解释"同体"要求
	- 区分"作用在两个物体"vs"作用在一个物体"
3. **AI物理助教**
	- 问答助手：回答学生的疑问
